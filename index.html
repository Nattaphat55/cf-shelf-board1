ส่วนบน: ค้นหาตาม Model → ส่วนล่าง: แผนผังตำแหน่งจริง — รหัส: ชั้นวาง-ชั้นที่-ล็อก

🗺️ แผนผังพื้นที่จัดเก็บ C/F

มุมมองจากด้านบน (Top View) — คลิกที่กล่องชั้นวางเพื่อเปิดป้ายตำแหน่งของชั้นนั้น

หมายเหตุ: ชั้น B/C/D/E เป็นรางเลื่อน เลื่อนเข้า-ออกได้ในแนวตั้ง 1-5 ของแต่ละชั้นเพื่อหยิบ C/F • ทิศทางเลข Lock ของ A สวนทางกับ B/C/D/E

🏭 โซนไลน์ผลิต — Line D

มุมมองจากด้านบน (Top View) — คลิกที่กล่องพื้นที่ข้าง Line D เพื่อเปิดป้ายตำแหน่ง (แยกทางเดินจากห้องเก็บของหลัก)

หมายเหตุ: โซนนี้อยู่คนละฝั่งทางเดินกับห้องเก็บของหลัก (Lab/A-E) — พื้นที่ข้าง Line D เป็นพื้นราบเรียงตำแหน่งเดียว ไม่มีชั้น/ล็อกแบบชั้นวาง — เริ่มนับจากฝั่งไกล Line D (1 = ไกลสุด, 15 = ติดเครื่อง)
🔄 เอาออก–เอาเข้า C/F
หยิบออกจากชั้น = กด “เอาออก” · เอากลับเข้าชั้น = กด “เอาเข้า” · รหัส: ชั้นวาง-ชั้นที่-ล็อก
